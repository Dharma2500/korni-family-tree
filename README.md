# Корни

Простое Android-приложение для создания и просмотра семейного древа.

## Сборка APK

APK собирается автоматически через GitHub Actions при каждом push в ветку \`main\`.

1. Откройте вкладку **Actions**.
2. Выберите запуск **Сборка APK**.
3. Дождитесь статуса **Success**.
4. Внизу страницы запуска скачайте архив **Korni-Android-APK**.
5. Распакуйте архив и установите \`app-debug.apk\` на Android.

Для запуска сборки вручную используйте **Actions → Сборка APK → Run workflow**.

## Основные принципы

- Весь интерфейс приложения на русском языке.
- Семейные данные хранятся локально на устройстве.
- Для работы с древом не требуется подключение к интернету.
- Экспорт и резервное копирование выполняются по запросу пользователя.
- В репозитории находится только исходный код, личные семейные данные сюда не отправляются.

## Технологии

- Kotlin
- Jetpack Compose
- Android SDK
- GitHub Actions
